# Eggy Cat site

Privacy policies and support pages for Eggy Cat apps, published with GitHub Pages.

- `number-nook/privacy/` — Number Nook privacy policy
- `number-nook/support/` — Number Nook support
- `mole-logic/privacy/` — Mole Logic privacy policy
- `mole-logic/support/` — Mole Logic support
- `dig-deep/` — redirects to `mole-logic/` (the app was called Dig Deep before 2026-11-09)

Each app has its own folder, so links to existing pages never change.
